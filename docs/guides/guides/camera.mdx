# Camera

:::note Guide Source Code
Go to the <GuideLink projectName="Camera"/> guide project to see the source code for a fully working example of this guide.
:::

A 2D camera is essentially a transform that maps world coordinates to screen coordinates. It defines what part of your game world is visible and how it is displayed.
You can move everything around instead, but that's usually just doing the camera's job manually — and it gets messy fast.

What a 2D camera usually provides:

<NumberedList items={[
    <><code>Position</code> - where the view is centered or anchored</>,
    <><code>Zoom / Scale</code> - how large world units appear on screen</>,
    <><code>Rotation</code> - if the view can rotate</>,
    <><code>Viewport Size</code> - how much of the world is visible</>,
    <><code>World To Screen Conversions</code> - transforms world positions into screen positions</>,
    <><code>Culling Info</code> - which objects are actually visible</>,
]} />

_**The key difference:**_ moving something on screen via the camera vs. moving the object itself.

Here's a concrete example. Say Mario's screen X position is _**100**_. If you pan the camera left, Mario
appears to move right on screen — but his world X position never changed; it's still _**100**_.

In actual platformers, the camera has a **dead zone** — an area where Mario can move around
without the camera moving at all. Here's how it works:

Start with Mario at the center of the screen. When he walks left, the camera stays put and
Mario slides across the left side of the screen. His position in the game world is changing,
but the camera isn't.

Now Mario turns around and walks right. The moment he crosses back past center, the camera
starts moving right too. From the player's view, Mario stays near the center while the world
scrolls left behind him. It looks like Mario is running right — but actually, **both** Mario
and the camera are moving right in the game world. Mario's world position is increasing, and
the camera's world position is increasing to follow him.

This is the key difference: moving the camera makes everything on screen shift, but it
doesn't change where anything actually is in the game world.

    public Game()

        const int mapWidth = 2500;

        this.contentManager = ContentManager.Create();

### <span className="color-sub-step">Step 6.1: Zooming In & Out</span>

Now that we have the current state of the mouse, add more code to the `OnUpdate()` method to
use the state of the mouse to check which direction the user is scrolling the mouse wheel.
If the user is scrolling the mouse wheel, we will zoom in and out.

```csharp showLineNumbers
protected override void OnUpdate(FrameTime frameTime)
{
    // Calculate zoom change per frame based on elapsed time.
    // Multiplying by elapsed time makes zoom speed consistent regardless of frame rate.
    var camZoomVelocityIn = (float)frameTime.ElapsedTime.TotalSeconds * CamZoomSpeed;
    var camZoomVelocityOut = (float)frameTime.ElapsedTime.TotalSeconds * CamZoomSpeed;

    // Get the current state of the mouse (position, buttons, scroll wheel)
    var currentMouseState = this.mouse.GetState();
    // highlight-add-start

    // Get the current state of the mouse (position, buttons, scroll wheel)
    var currentMouseState = this.mouse.GetState();

    // Get the scroll wheel value to control the zoom level of the map
    var scrollValue = currentMouseState.GetScrollWheelValue();

    if (scrollValue > 0)
    {
        // Scroll up = zoom IN (see less of the map, but bigger)
        this.camera.Zoom += camZoomVelocityIn;
    }
    else if (scrollValue < 0)
    {
        // Scroll down = zoom OUT (see more of the map, but smaller)
        this.camera.Zoom -= camZoomVelocityOut;
    }
    // highlight-add-end

    base.OnUpdate(frameTime);
}
```

### <span className="color-sub-step">Step 6.2: Panning Camera</span>

Now for the panning of the camera. If the map is zoomed out 100%, then we can see the entire map,
so panning the camera has no real use. But what if we are zoomed into the map and we cannot see
the entire map?  This is where panning, (moving the camera's position) comes in.

Add code to the `OnUpdate()` method to check if the left mouse button is being held down.
If so, we can then see if the mouse is dragging, which it is not when we first press
down the mouse button. At this point, we set the mouse state into dragging mode, record
the starting position, and the camera position.

We will then calculate the difference (delta) between the current mouse's position and the
position of the mouse when we pressed the button.  This difference will then be used to
calculate the new position for the camera.

:::info Delta?
The reason we need the delta is because the position of the map is relative to it's center.
This means if we click the mouse anywhere else on the screen that is not the center, the map
will teleport to the mouse every time we click the mouse button.  The delta represents
the distance between the center of the map which it's position vs where we clicked. 

Essentially, this let's us drag the camera based on where we clicked instead of the center
of the map.
:::

```csharp showLineNumbers
protected override void OnUpdate(FrameTime frameTime)
{
    // ... other code

    if (scrollValue > 0)
    {
        // Scroll up = zoom IN (see less of the map, but bigger)
        this.camera.Zoom += camZoomVelocityIn;
    }
    else if (scrollValue < 0)
    {
        // Scroll down = zoom OUT (see more of the map, but smaller)
        this.camera.Zoom -= camZoomVelocityOut;
    }
    // highlight-add-start

    // If the mouse is down, we can pan the camera
    if (currentMouseState.IsLeftButtonDown())
    {
        // Get the current mouse position in screen pixels
        var currentMousePos = currentMouseState.GetPosition();

        if (!this.isDragging)
        {
            // This is the FIRST frame of the drag — remember where we started.
            // We need both the mouse position (screen px) and camera position (world units)
            // so we can calculate how far things have moved.
            this.isDragging = true;
            this.dragStartMousePos = currentMousePos;
            this.dragStartCameraPos = this.camera.Position;
        }

        // Calculate how far the mouse has moved since the drag started (in screen pixels)
        var delta = new Vector2(
            currentMousePos.X - this.dragStartMousePos.X,
            currentMousePos.Y - this.dragStartMousePos.Y);

        /*
            * Convert the mouse movement into camera movement.
            *
            * The formula: camera.Position = dragStartCameraPos - (delta / camera.Zoom)
            *
            * WHY NEGATIVE?
            *   Moving the camera RIGHT makes the world appear to move LEFT on screen.
            *   To make the map follow the mouse (move right when the mouse moves right),
            *   we move the camera in the OPPOSITE direction of the mouse.
            * WHY DIVIDE BY ZOOM?
            *   The mouse delta is in SCREEN pixels, but camera.Position is in WORLD units.
            *   At 50% zoom, moving the camera by 100 world units only moves the view by 50 screen pixels.
            *   Dividing the mouse delta by Zoom converts screen pixels → world units,
            *   so the grabbed point on the map stays exactly under the cursor at any zoom level.
        */
        this.camera.Position = this.dragStartCameraPos - (delta / this.camera.Zoom);
    }
    else
    {
        // Mouse button is not pressed — end the drag
        this.isDragging = false;
    }

    // highlight-add-end
    base.OnUpdate(frameTime);
}
```

## <span className="color-step">Step 7: Rendering The Game</span>

With all of the content being loaded and game logic and behavior implemented, we can now
render the map based on the map and camera position.

### <span className="color-sub-step">Step 7.1: Camera Transformations</span>

Add a `OnDraw()` method to the class with the following code.  This uses the camera to transform the
maps position in world and size space to a position and size in screen space.

```csharp showLineNumbers
public class Game : Window
{
    // ... other code
    // highlight-add-start
    protected override void OnDraw(FrameTime frameTime)
    {
        if (this.font is null)
        {
            throw new InvalidOperationException("Font was not loaded.");
        }

        // Transform the map's WORLD position to a SCREEN position
        // This applies the camera's pan (Position) and zoom, converting where the map
        // exists in the world to where it should be drawn on the screen
        var mapPos = this.camera.TransformPosition(this.mapWorldPos);

        // Get the scale factor for rendering. TransformSize multiplies by the camera's Zoom,
        // so at 50% zoom, the map is drawn at half size
        var textureScale = this.camera.TransformSize(1f);

        // Show the current zoom level in the window title
        Title = $"Camera Guide | Zoom: {this.camera.Zoom}";

        base.OnDraw(frameTime);
    }
    // highlight-add-end
}
```

### <span className="color-sub-step">Step 7.2: Render Map & Instructions</span>

Now that we have our position and size in screen space, we can use those values to render the map texture.
Add the following code to the `OnDraw()` method to do this. We also will render the instruction text to
to screen as well.

```csharp showLineNumbers
protected override void OnDraw(FrameTime frameTime)
{
    // ... other code
    // highlight-add-start

    // Begin a batch of draw calls. Everything between Begin() and End() is grouped
    // together and sent to the GPU efficiently in one operation
    this.batcher.Begin();

    // Draw the map.
    this.textureRenderer.Render(
        this.metroidMapTexture,
        mapPos, // WHERE to draw (screen position after camera transform)
        0f, // No rotation
        textureScale, // HOW BIG to draw (affected by camera zoom)
        -100); // Z-index (lower values are drawn behind higher values)

    // Draw the instructions text.
    // NOTE: We use raw screen coordinates here (not camera.TransformPosition)
    // because we want the text to stay fixed on the screen, not move with the map
    this.textRenderer.Render(
        this.font,
        this.instructionsText,
        new Vector2(150, 60f), // Screen position (fixed, not affected by camera)
        0.5f, // Text scale
        0f, // Rotation in degrees
        Color.White);

    // End the batch — submit all the draw calls to the GPU
    this.batcher.End();

    // highlight-add-end
    base.OnDraw(frameTime);
}
```
